# Glossary: Dutch terms in the source, and their English UI words

OpenRoots grew out of a Dutch family chart. Identifiers in the code (class names, function names,
variables, route names, data keys) are still Dutch. They are stable and will be renamed in
a later pass. Only text that people read is English. This table fixes the English words so the
whole interface sounds the same.

## Evidence and status (keep these four exactly)

| Code name | Dutch label | English label | Meaning |
|---|---|---|---|
| akte | bevestigd door een akte | Confirmed by a record | A record names the person and the link |
| onderbouwd (OB) | onderbouwd | Supported | Sound argument from indirect evidence |
| voorbehoud (VB) | onder voorbehoud | With reservation | Fits the evidence, other readings remain |
| nietbevestigd (NB) | niet bevestigd | Unconfirmed | A lead only, such as another person's tree |

Colour never stands for evidence. The status is always shown by a shape and a label too.

## Symbols (keep as they are)

`°` born, `†` died, `⚭` married, `≈` estimated.

## Writing style

- Plain international English with British spelling (colour, grey, neighbour).
- Dates read as `12 October 1835` in sentences. The data files use `DD-MM-YYYY`, `MM-YYYY` or `YYYY`
  and English month names (`March 1884`).
- Short sentences. No jargon the reader would not know.
- Do not translate proper names of archives and websites. Give a translation in brackets the
  first time only if it helps, for example "Nationaal Archief (National Archives of the Netherlands)".
